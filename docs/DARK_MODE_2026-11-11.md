# HANBOM DATA — 자동/라이트/다크 테마 개발기

기준: 2026-11-11 · 버전 2.1.0 · 기존 82종 RSS·23개 메뉴·129개 pill Web Component 유지

## 목표

- 시스템의 색상 모드를 기본값으로 사용하는 다크모드 추가.
- 사용자가 `자동`, `라이트`, `다크` 세 가지를 명시적으로 전환 가능.
- 수동 선택은 브라우저 `localStorage`에 저장하고 새로고침 뒤에도 복원.
- 다시 `자동` 선택 시 저장된 강제 설정을 삭제해 OS 설정으로 복귀.
- 기존 밝은 화면 디자인·주아체·Flex/Grid 레이아웃·MCP 68개·공개 RSS 82개·3 shard 캐시 등 운영 기능 보존.

## 실제 동작

1. 브라우저에 수동 저장값이 없다면 OS `prefers-color-scheme: dark` 미디어쿼리를 따른다. OS 설정이 변경될 때도 자동으로 갱신한다.
2. 수동 선택값이 `dark` 또는 `light`라면 `data-theme` 속성과 CSS 토큰으로 OS 설정보다 우선한다.
3. `THEME_BOOT`는 `<head>`에서 CSS 전에 실행되어 저장된 dark 모드에서 하얗게 반짝이는 FOUC를 방지한다. `<meta name="theme-color">`도 초기 모드에 맞게 업데이트한다.
4. 하단 `THEME_CLIENT`는 `role="group"`의 세 가지 네이티브 버튼 `aria-pressed` 상태를 동기화한다. 버튼의 마우스 hover 애니메이션은 적용하지 않는다.
5. 저장소가 비활성화된 브라우저에서도 `try/catch`로 오류 없이 세션에서 테마 전환이 가능하도록 한다.
6. `자동` 선택 시 저장값을 제거하고 즉시 OS 설정으로 돌아간다.

## 접근성·호환성

- 네이티브 `button type="button"`의 Tab/Enter/Space 조작 유지.
- `role="group"` + `aria-label="화면 테마"`, 각 버튼의 `aria-pressed`로 선택 여부 제공.
- `<meta name="color-scheme" content="light dark">`와 CSS `color-scheme` 조합으로 브라우저 기본 요소 색상도 모드에 맞춤.
- CSS `@media(prefers-color-scheme:dark)`로 JS가 실행되지 않아도 시스템 다크 모드에 반응.
- 320px·360px에서도 컨트롤은 본문 너비 내에 유지하도록 작게 구성.
