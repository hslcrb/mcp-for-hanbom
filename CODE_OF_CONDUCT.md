# Community code of conduct

HANBOM DATA is an open source project built to make public school and
higher-education information easier to explore.

Contributors and users should be considerate and professional. Treat
questions, corrections and code reviews respectfully. Avoid harassment,
personal attacks, discriminatory abuse and publishing another person's
private information.

Do not share credentials, private API screenshots, students' names from
restricted sources, or identifying details from counseling or reporting
records. When discussions contain sensitive material, contact the
maintainer privately.

The repository maintainer may remove harmful content, close disruptive
threads or restrict participation where necessary. Changes to project
governance should be discussed openly in non-sensitive issues.
